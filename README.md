# amanullah-bio

Source of [amanullah.dev](https://amanullah.dev): the portfolio of Amanullah,
M.Sc. Molecular Biotechnology (Hochschule Anhalt), working toward computational biology.

Plain HTML and CSS: no build step, no JavaScript, nothing to maintain.

```
index.html     the page
styles.css     the styles (light and dark)
favicon.svg    the tab icon
```

Every push to `main` deploys on Vercel.
